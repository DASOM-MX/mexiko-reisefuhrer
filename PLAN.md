# Plan and checkpoints

Where the Angular → Cloudflare EmDash migration stands, so work can resume
later. Setup, deploy and design rules are in `README.md` and `AGENTS.md`.

Last updated: 2026-11-03 (branch `emdash`).

## Client brief

- Non-technical editor (licensed tour guide) writes blog posts, edits content
  and adds testimonials from the admin.
- Contact submissions are stored **and** emailed. WhatsApp is out of scope for now.
- Full redesign: option **3a** from the Claude Design project "Facelift Home".
- Languages: German (default, unprefixed), English (`/en`), Spanish (`/es`).

## Known caveats

- EmDash builds sitemap/hreflang URLs from one `urlPattern` (`/galerie/{slug}`),
  so EN/ES album URLs appear as `/en/galerie/…` and `/es/galerie/…`. Those routes
  301 to `/en/gallery/…` and `/es/galeria/…`. Keep the redirect routes.
- Seeded translations don't inherit non-translatable fields, which is why the seed
  repeats images in every locale. The seed is generated by a Python script that
  was not committed; edit `seed/seed.json` directly or regenerate a builder.
- Schema changes to existing collections need a local reset: delete
  `.wrangler/state`, start dev, open `/_emdash/api/setup/dev-bypass?redirect=/`,
  re-run the forms script, then `npx emdash types`.
